# 交付说明（快速上手）

本包为「DSH 飞书机器人 × 企业信息安全框架」的完整交付。详细过程见《工作汇报-详细.md》。

## 包内有什么

| 目录/文件 | 内容 |
|---|---|
| `stay-DSH/` | 加固版 dsh-lark 源码工程（三级分级管控 + 审计），含 .git 可直接推送 GitHub |
| `部署配置/lark-profile-安全基线配置.yml` | 已脱敏的机器人安全配置模板（部署前替换示例值） |
| `部署配置/start-lark-bot.cmd` | 机器人启动脚本（可放入启动文件夹自启） |
| `文档/` | 改造清单与对标分析 |

## 30 秒上手

1. **启动机器人**：运行 `部署配置\start-lark-bot.cmd`（或在登录后由启动文件夹自动拉起）；
2. **飞书私聊机器人**：发正常消息直接执行；发含"订单号/BOM 表"等敏感词 → 弹提醒确认；发含手机号/身份证 → 拦截并提示脱敏；
3. **看审计**：`%USERPROFILE%\.dsh\logs\lark-audit.jsonl`（谁/何时/什么处置，PII 已剥离）。

## 重新部署（新机器）

```sh
npm i -g @deepseek-ai/dsh              # 需 Node ^22.19 || >=24
dsh plugin --profile lark add <本包 stay-DSH 的 tarball 或源码构建>
# 将 部署配置/lark-profile-安全基线配置.yml 内容写入 $DSH_HOME/profiles/lark/cordis.patch.yml
dsh --profile lark                     # 首次会打印二维码创建飞书应用
```

## 推送 GitHub（网络正常时）

```sh
cd stay-DSH
git remote set-url origin https://github.com/<github-account>/stay-DSH.git
git push -u origin main
# 如遇 Connection reset，加参数重试：
git -c http.version=HTTP/1.1 -c http.postBuffer=524288000 push -u origin main
```

## 安全提醒

- 本包**不含**公司手册原文与任何密钥（在 `~/.dsh` 凭据存储与系统凭据中）；
- `部署配置` 仅含示例 Open ID；部署前请替换为获批账号，并保持仓库私有；
- 待安全部授权后：回填 `approvers` 并改 `onRed: approval` 即可启用红区审批模式。
