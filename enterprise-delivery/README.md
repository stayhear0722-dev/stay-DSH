# 企业信息安全交付资料

本目录包含 DSH 飞书通道的企业信息安全分析、部署模板和工作记录，仅限内部使用，不应复制到公开仓库。

## 脱敏状态

- 飞书 App ID、用户 Open ID、内部邮箱、人员姓名、公司名称、知识库对象标识和个人电脑路径均已替换为示例值。
- `部署配置/lark-profile-安全基线配置.yml` 是模板；部署前必须由获批人员填写真实白名单和工作区。
- 飞书 App Secret 和其他凭据只允许通过环境变量或受管凭据存储注入，不得写入仓库。

## 仍属于内部资料的内容

- 企业安全手册要求的摘要和映射；
- 安全控制架构、权限边界、审计设计与分级规则；
- 当前部署状态、测试结果、待完善能力和风险分析。

仓库必须保持私有。对外分享前，应再次执行敏感信息扫描，并由信息安全负责人审核。
