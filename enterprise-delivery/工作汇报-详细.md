## 三、详细工作过程

### 1. 开源调研（找仓库）

- 用户记忆中的仓库名 `omdsm-dev/dsh-lark` 与真实名 **`omdsh-dev/dsh-lark`** 有差异（多了个 h），已通过 GitHub 搜索确认并定位；
- 功能核实（README + 源码）：Cordis 插件形式接入 DSH，飞书**长连接**收发（无需公网服务器/回调）、扫码创建应用、计划/工具审批回飞书交互卡片、`/ws` `/cd` `/model` 命令、多 Agent 协作；
- 环境兼容性核查：Node v24.18.0 ✅、DSH 0.1.0-rc.6 ✅（插件要求 ≥0.1.0-rc.6）、npm 最新版 0.0.6 ✅。

### 2. 企业安全定制分析（对 WorkBuddy / 千问办公）

对标产品安全基线（web 调研）：
- **WorkBuddy（腾讯）**：SaaS/VPC/私有化一体机，信通院认证、Prompt 防护、数据隔离，大厂 SRE 兜底；
- **千问办公（阿里）**：国内首个通过信通院办公智能体评估，SaaS 为主。

结论：商业产品护城河是「认证背书 + 大厂运维」；自建天然优势是「**数据不出域 + 人在回路 + 全链路可审计**」。改造方向 = 用开源组件把审计、输入红线、输出管控、受管运行补齐。

### 3. 手册读取（定位 + 提取）

- 通过公司内部知识库定位安全手册（具体知识库路径、文件对象标识与原文位置已脱敏）；
- 下载：`drive +download` 被权限拒绝 → 改用 `drive +preview --type source_file` 拿到 PDF（844 KB）；
- 提取：`pdftotext` 中文全部丢失（字体编码问题）→ 用 **pdfjs-dist** 写脚本成功提取 30 页全文（25316 字符，`员工信息安全手册-pdfjs.txt`）；
- 手册要点（14 章）：数据分级 L1-L4、密码规范、飞书文档外发管控、设备/网络/物理安全、**第 10 章生成式 AI 使用规范**（数据输入红线、人在回路、运行环境隔离、凭证管控）、事件上报（security@example.com）、合规（PIPL/GDPR/CCPA）。

### 4. 改造实施（fork 开发，Phase 3）

在 `C:\Path\To\ApprovedWorkspace\dsh-lark` 克隆上开发（branch: `security-hardening`），新增：

| 模块 | 作用 |

### 5. 部署实施（Phase 0/1/2）

1. **创建独立 profile**：`dsh plugin --profile lark add dsh-lark-channel@latest`（与运行中的 web GUI 隔离，符合手册 10.10 运行环境隔离）；
2. **替换加固版**：`pnpm pack` 打包 fork → `pnpm add <tarball>` 装入 lark profile（依赖指向本地 tarball）；
3. **修复 patch 语法**：首次启动报 `duplicate loader entry id: lark-channel` → 改为 **id-targeted config 覆盖**（不 insert 同名行）→ 启动成功；
4. **上线**：`dsh --profile lark` 启动 → 打印二维码 → 用户飞书扫码创建应用 **cli_example_enterprise_app** → 凭据存入凭据存储（settings 只留引用）→ **WebSocket 长连接就绪**；
5. **安全基线配置**（`~/.dsh/profiles/lark/cordis.patch.yml`）：
   - `senderAllowlist`：两个示例账号 open_id（安全管理员 + 应用注册账号，真实标识已脱敏）；
   - `workspaceRoots`：`C:\Path\To\ApprovedWorkspace`（/cd 边界）；
   - `onRed: block`（红区拦截，**不需要审批人**，符合小职员背景；approvers 留空作框架，回填即启用审批模式）；
   - `onYellow: remind`、`remindDedupeMinutes: 5`；`requireMention: true`、`attachImages: false`、`sessionScope: chat-thread`；
   - 审计默认开启（红区强制留痕，日志 `~/.dsh/logs/lark-audit.jsonl`）；
6. **自启（免管理员）**：`start-lark-bot.cmd` 放入「启动文件夹」（`%APPDATA%\...\Startup`），登录即自动拉起；脚本显式开启 TLS 校验。

## 五、使用说明

**启动机器人**：
```
C:\Path\To\ApprovedWorkspace\start-lark-bot.cmd
```
（或登录后由「启动文件夹」自动拉起）

**在飞书使用**：私聊机器人（白名单内账号）→ 发消息派任务；群里需 @。
- 正常业务消息：直接执行（绿区）；
- 含敏感词（如"订单号"、"BOM 表"）：弹提醒卡片，确认后继续（黄区）；
- 含手机号/身份证等 PII：拦截并提示脱敏（红区，默认拦截）。

**查看审计日志**：
```
%USERPROFILE%\.dsh\logs\lark-audit.jsonl
```
每条记录含时间戳、来源、处置动作、命中特征、处理人；PII 已剥离。

**停止**：任务管理器结束 `node` 相关进程，或关闭启动脚本窗口。
